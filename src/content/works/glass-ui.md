## 起因

我一直想给自己的网站换一套「看起来认真做过」的视觉，而不是套模板的白底黑字。研究了一圈深色系产品站之后，我把配方收敛成四个关键词：**玻璃、梯度、留白、错峰**。

## 玻璃：用内高光，不用外投影

深色界面上，卡片如果加传统投影会显得脏。正确的做法是给卡片顶部一条 1px 的半透明白色内高光：

```css
box-shadow: inset 0 1px 0 hsla(0, 0%, 100%, 0.12);
```

配合 6% 透明度的白色表面层，卡片就像浮在页面之上的玻璃板——这正是「高级感」的物理来源：真实世界里的玻璃边缘就是这样反光的。

## 梯度与旋转描边

输入框、命令条这类「可交互的容器」，静止时是 1px 的淡边框；hover 时用一条 conic 渐变光带绕着边缘旋转。技术上需要 `@property` 注册角度变量才能动画化渐变的旋转，光带用两层 mask 挖空只留边框。

## 错峰入场

首屏元素不要同时出现。同一个「淡入 + 上浮 + 去模糊」动画，从 0 秒开始每 80~100ms 错峰一个元素，视线会被引导着从上往下读完整个 hero 区——动效在这里的作用不是炫，而是**编排阅读顺序**。

## 留白是最后 20%

容器宽度控制在 1200px 出头，section 之间留 120px 以上。敢留白，本身就是一种设计声明：内容不多，但每一条都在意。
